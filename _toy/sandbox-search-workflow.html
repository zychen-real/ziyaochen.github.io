SANDBOX SEARCH WORKFLOW —— 把一次搜索拆成可配置的流水线，左边填参数，右边逐轮跑，每一步的中间结果都摊开来看。

时长 02:17 分辨率 3456×2234 → 1920×1240 编码 H.264（无音轨） 大小 23 MB
下载视频（mp4 · 23 MB）

这是什么

一个搜索链路的沙盒调试台。填入用户查询和画像，系统按固定编排逐轮执行： 改写 query → 检索公众号文章 / 网页 → 提取 nugget → 缺口分析， 并在收敛后综合出最终答案。和自主 Agent 的区别在于：这里的每一步、每一轮都是 预先编排好的，参数明确、过程可复现。

执行链路

用户查询 + 用户信息 + 用户上下文 + 搜索时间 │ ▼ ┌─────────────────────────────────────────┐ │ 改写 query │ │ ↓ │ │ 检索：公众号搜索 / 网页搜索 / 视频号搜索 │ │ ↓ │ │ 提取 nugget │ │ ↓ │ │ 缺口分析 ──── 未收敛 ──→ 下一轮（最多 N 轮） └─────────────────────────────────────────┘ │ 收敛 ▼ 综合生成最终答案

可配置项

视频里左侧面板从上到下依次是：

分组参数
输入用户查询（必填）、用户信息（地域 / 画像，可选）、用户上下文（历史行为，可选）、搜索时间（默认当前时刻）
LLM 调用源knot 智能体 / qwen (xiaocai) —— 整条链路 4 段统一生效
检索通道公众号搜索网页搜索视频号搜索脉络卡片
链路开关首轮仅原 query（第一轮不改写）需求偏移检测
轮次控制单 Sub Query 篇数、最大轮次、每轮 query 数、每轮文档上限

顶栏还有 批量任务、历史归档 两个入口，以及跳转到 SANDBOX AGENT 的链接。 右上角的空闲 / 忙碌指示灯用来看当前是否有任务在跑。

说明

  • 原视频是 .mov（Retina 录屏，3456×2234，376 MB，无音轨）。已用 ffmpeg 转码为 1920×1240 H.264 mp4（23 MB），并截第 5 秒的帧做封面。
  • 演示环境跑在内网 IP 上，属于本地沙盒，非公开服务。
  • 本文的链路与参数说明取自视频界面的可见信息；具体实现细节未展开。
