这是 Toy 合集的第一条记录 —— 一个跑在 macOS 上的本地知识库小工具演示。视频里走了一遍从启动、索引本地文档、到问答检索的完整流程。

时长 02:23 分辨率 3456×2234 → 1920×1240 编码 H.264 / AAC 大小 7.1 MB
下载视频（mp4 · 7.1 MB）

关于这个小工具

完全跑在本地，文档不出本机。索引、检索、问答都在 macOS 进程内完成，不需要任何云端 API， 适合随手攒一些笔记、代码片段、PDF 又不想上传到第三方服务的场景。

基本信息

项目说明
平台macOS 14+（Apple Silicon 原生，Intel 兼容）
安装下载后直接拖入 Applications
索引位置~/Library/Application Support/LocalKB/
支持格式TXT / Markdown / PDF / 代码文件
网络依赖无（纯本地运行）

演示流程

  1. 启动应用，选择一个本地资料目录（例如 ~/Documents/notes）。
  2. 首次扫描：自动抽取文本、切片、向量化、写入本地索引。
  3. 进入问答界面，输入问题 → 检索相关片段 → 拼接答案。
  4. 所有中间产物都保留在本机，重启后无需重新索引。
