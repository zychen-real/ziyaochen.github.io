这是什么

用 ESP32 做的一个桌面语音小玩具：麦克风拾音 → 语音识别 → 大模型对话 → 语音合成 → 喇叭播放，整个链路跑通后就成了一个能聊天的小伙伴。 取名「机器人女友」纯属自娱，重点在把语音交互闭环塞进一块几十块钱的开发板。

用到的东西

环节方案
主控ESP32（带 Wi-Fi，负责联网和音频 I/O）
输入麦克风模块拾音
输出小喇叭 / 功放模块
对话云端大模型 API
录制手机竖屏直录，含现场环境音

说明

  • 视频为手机竖屏实拍（720×1280），保留了原始音轨，建议戴耳机或开喇叭观看。
  • 这是自己攒的玩具，不是成品；接线和外壳都很随意，重点看交互效果。
