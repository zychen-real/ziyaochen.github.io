0执行摘要（TL;DR）

一分钟看懂这半个月生成式召回领域发生了什么、值多少关注。

Deep Research Generative Retrieval Semantic ID Industrial Deployment

本报告覆盖 2026-08-31 ~ 2026-09-14 半月窗口内生成式召回（含生成式检索 GenIR、生成式推荐召回、LLM 驱动的召回通道）的最新动态，共收录窗口内新论文/新落地动态 14+ 条，全部标注日期与原文链接。核心结论如下：

① 生成式召回正从推荐场景向搜索场景加速渗透

本半月最显著的信号是搜索场景工业落地的批量出现：阿里天猫搜索公开 CQ-SID（CIKM 2026，2026-09-04），把生成式检索定位为搜索召回中的一路补充而非端到端替换；百度电商搜索端到端 GR 通道上线（CTR +3.52%订单 +15.96%GMV +7.53%）；Apple 发布 CoGR（2026-09-01），用双端 LLM 生成关键词走存量倒排索引实现生成式召回。搜索场景"高相关、低容错"的特性，正在把生成式召回从"端到端替换"修正为"可控的召回增强路"。

② Semantic ID 构建进入"几何与信息论精细化"阶段

半月内出现三条 SID 构建新路线：HypRQ-VAE（2026-09-04）把残差量化搬进双曲空间以保护长尾层级分布；Bottom-Up Clustering（2026-09-08）用自底向上聚类在唯一性与局部结构间求平衡；百度系 ICEGR（2026-09-10）用共点击意图图把 query 意图注入 SID 量化。SID 不再只是"量化压缩"，而是召回决策空间的显式设计变量。

③ 解码面成为新的显式工程优化对象

WIDE（2026-09-05）在跨模态生成式检索中引入通配符解码：当模型对细粒度 token 不确定时发出 wildcard 扩展搜索空间，避免"强制幻觉"；腾讯 TGR/BARGE（2026-09-02）修复层级 SID 生成的 item 边界丢失与语义漂移两大结构缺陷，Hit@5 超 OneRec 10.2~16.9%；扩散去噪召回（EPIC）同步推进。"生成什么、何时承认不确定、何时保持候选"正在成为显式工程决策。

④ GRPO 类强化学习成为召回对齐的事实标准

半月内至少 5 个工作使用 GRPO 及其变体做召回对齐：天猫 EG-GRPO（专家引导，向策略梯度群组注入真实 GT 样本）、Apple CoGR（query/item 双端交替协同进化，item 侧用反事实边际奖励）、阿里国际 EAGER（课程 SFT + 混合奖励 GRPO）、腾讯系 SSR-GRPO（双视角相关性去偏）。RL 奖励信号设计（业务分注入、反事实分解、专家引导）是当前比拼焦点。

⑤ 可复现性与评测基建开始补课

ReDSI（2026-09-08）发布首个完整开源的 DSI 实现（覆盖 atomic/naive/semantic 三种文档标识符）与参数化 NQ320K 构建流水线，直指 DSI 基线可复现性差、评测不一致的老问题；结合 5 月 SID 碰撞可致 Hit@10 高估 103% 的发现，生成式召回的评测方法论正在被系统性重审。

本半月最值得精读的三篇 ① CoGR（arXiv 2609.00638）——"生成式表示 + 存量倒排基建 + 双端协同 RL"的组合拳，对拥有成熟倒排基建的搜索团队参考价值极高；② CQ-SID（CIKM 2026 工业文章）——搜索召回场景最完整的落地细节（SID 设计→渐进 SFT→EG-GRPO 对齐）；③ TGR（arXiv 2609.00986）——腾讯把生成式排序与生成式召回统一进一个工业框架的体系化尝试。

2主题一：Semantic ID 构建与量化

SID 是生成式召回的"地基"。半月内的三条新路线（双曲几何、自底向上聚类、意图注入）表明：SID 设计已经从"怎么压缩"升级为"召回决策空间长什么样"的一等设计问题。

Semantic ID RQ-VAE 双曲空间 长尾与冷启动

2.1 演进背景：从 RQ-VAE 到"精细化设计"的三级跳

回顾 SID 构建的技术脉络，可以清晰看到三代范式：

HypRQ-VAE：Hyperbolic Item Indexing for Long-Tail-Aware Generative Recommender Systems

arXiv 2609.03369 2026-09-04 双曲几何 长尾感知
动机

欧氏空间下的残差量化对"少数头部 + 大量长尾"的幂律分布天然不友好：树状/层级语义结构在欧氏空间中被过度压缩，长尾 item 容易被挤进同一个码字桶，加剧 SID 碰撞与长尾召回劣化。

方法
  • 保留残差量化的"粗到细"码字结构，但把整个索引几何搬进双曲空间——双曲空间对树形/层级结构具有天然的嵌入式优势（指数级体积增长），等距映射下长尾分支可获得更大的量化分辨率；
  • 首个将双曲几何引入 RQ-VAE item 索引的框架（Hyperbolic Residual-Quantized VAE）。
评价

思路与 5 月"SID 碰撞可高估 Hit@10 达 103%"的评测发现互为呼应——碰撞的根源之一是几何失配。工程上可置于离线 item tokenizer 层周期性重建，不动线上排序模型，落地风险低；但双曲运算的数值稳定性与与既有 LLM 词表的衔接细节需验证。

📄 原文：arxiv.org/abs/2609.03369 · 解读：liuzhao09 笔记

Bottom-Up Clustering for Creating Semantic IDs：自底向上聚类构建 SID

arXiv 2609.08310 2026-09-08 聚类算法 唯一性 × 结构保留
动机

SID 构建的两大核心挑战：①唯一性——每个标识符应映射到唯一 item（避免碰撞）；②信息保留——量化过程应保留对下游任务有价值的嵌入结构信息。既有做法（追加去重码字、残差量化层次聚类）往往顾此失彼。

方法
  • 提出自底向上聚类（bottom-up / agglomerative 风格）的新算法：从细粒度局部结构出发逐层合并，使最终 SID 同时满足唯一性与局部结构保留；
  • 与 RQ-VAE 的"自顶向下残差"形成方法论互补——先保住局部邻域，再谈层级抽象。
评价

价值在于把"SID 质量评估"从下游 GR 训练结果中解耦出来直接优化聚类质量，与 FORGE（KDD 2026）提出的"无需训练即可评估 SID 质量"的思路同向；对工业侧而言，这类纯离线、可独立评测的 SID 改进是风险最低的迭代入口。

ICEGR / IA-SID（中科大 + 百度，WSDM 2027）：意图图注入的 SID 构造与全链路对齐

WSDM 2027 投稿 2026-09-10（行业报道） 意图一致性 已上线百度电商
动机

电商搜索 GR 通道中，SID 由 item 内容决定，但用户真正检索的是"意图"；低曝光商品缺少 query 级监督，意图与 SID 之间存在错位。

方法（三段式）
  • IA-SID：用共点击关系构图，经 embedding 对齐 + 图传播 + 意图融合后再量化，把意图信息注入 SID 构造；
  • SQE-SFT：以多粒度合成查询为低曝光商品补充 query 级监督；
  • RCPO：相关性校准的 margin-adaptive 偏好优化，平衡业务信号与意图匹配。
结果

离线 Recall@20 +21.7%NDCG@20 +26.6%线上 CTR +3.52%订单 +15.96%GMV +7.53% —— 百度电商搜索端到端 GR 通道已上线。

评价

这是半月内线上收益最完整披露的搜索侧 GR 工作。"意图贯穿"（构造→监督→偏好优化三层一致性）的方法论对任何 query 驱动的召回场景（含搜索、I2I、广告触发）都有直接参考价值。

📰 详见第 7 章工业落地盘点（百度电商部分）
与既有内部的呼应 内部 7 月调研已指出 SID 全生命周期六个环节（初始化质心、分布 Tlow、结构 InforID、诊断 ISD、推理 SIDReasoner、动态目标 TAGR）均有工业验证。本月三条新路线（双曲几何、自底向上聚类、意图注入）相当于把"几何"与"意图"两个此前偏学术的环节补进了工业视野，SID 设计空间的"可审计性"（先审计、再初始化）仍是任何新链路的起点。

3主题二：解码与推理增强

自回归解码的"早剪枝"与"强制幻觉"是生成式召回的老大难。本半月的共识性进展是：把解码从"黑盒 beam search"变成"带不确定性感知的显式搜索过程"。

约束解码 通配符 扩散去噪 层级路径修复

WIDE：Wildcard Inference with Dynamic Expansion for Cross-Modal Generative Retrieval

arXiv 2609.03554 2026-09-05 跨模态检索 M-BEIR SOTA
动机

跨模态生成式检索中存在模态间信息不对称：文本 query 简洁，而视觉候选密集。自回归解码器在 trie 约束束搜索中猜不出 query 里缺失的细粒度细节，产生"强制幻觉"——被迫给出确定性 docid，无关候选抢占前排。

方法（三组件）
  • AET（自适应熵阈值）：离线校准各解码层的不确定性边界；
  • AWD（非对称感知通配符解码）：检测到语义盲点时发出通配符替代强制确定性标识符，动态扩展搜索空间且不产生 log-probability 惩罚；
  • BSR（盲点重排序）：以"离散生成置信度 + 连续语义相似度"混合评分对扩展后的候选池重排。
结果与评价

M-BEIR 基准上超越 SOTA 生成式检索方法，同时保持紧凑的标识符索引结构。方法论意义大于跨模态本身："何时承认不确定"被显式建模为解码动作，这与内部号内搜实践中"beam=40 下平均每个 SID 仍召回 19 个视频、SID 聚类与向量仍有优化空间"的观察同构——beam size 本质上就是在为解码不确定性买单，通配符提供了更结构化的替代方案。

📄 原文：arxiv.org/abs/2609.03554

TGR / BARGE（腾讯）：层级 SID 生成的结构性缺陷修复与全量上线

arXiv 2609.00986（TGR 技术报告） 2026-09-02 / BARGE 通道 09-03 全量 item 边界 + 语义漂移 工业上线
动机（两个结构缺口）
  • 多 token item 展平丢失 item 边界：将 item 编码为层级 SID 序列后展平进历史序列，模型无法感知"哪些 token 属于同一个 item"；
  • 前缀早期错误引发语义漂移：层级生成中第一级码字选错，后续所有细化都跑偏，且 beam 内路径缺乏纠偏机制。
方法
  • item context-aware attention：注意力中显式注入 item 边界上下文；
  • 层级路径重排：对 beam 内的部分路径按层级语义一致性重打分；
  • 正交双路径解码：两条独立解码路径互为校验，抑制单路径漂移。
结果

作为生成式召回通道全量上线：Hit@5 超 OneRec 10.2~16.9%CTR +0.60%总阅读时长 +1.70%，且上线后增益持续放大。TGR 整体框架（BARGE 召回 + HiGR 整列生成 + CCFormer）中新用户 Hit@1 +477.8%。

评价

这是对"层级 SID 生成"最体系化的一次缺陷诊断 + 修复 + 上线验证。与 8 月初知乎首篇 BARGE 解读形成闭环，确认了"结构缺陷修复"这一方向从论文走向生产的可行性。

3.1 扩散解码召回：EPIC 与路线现状

扩散去噪解码（代表工作 DiffuGR，2025-11 提出）提供了"全局并行、可回头修正"的替代范式，但去噪步数带来的延迟一直是落地瓶颈。本半月行业日报收录的 EPIC 把 item 级后验信息投影进扩散去噪过程，让去噪的中间态直接携带 item 结构先验，属于"用信息增量换去噪步数"的路线。结合内部 7 月调研的判断：扩散解码在"早剪枝"上的理论优势真实存在，但推理延迟高、训练复杂，短期定位仍是研究跟踪而非落地主线。

✅ 解码面进展的共性逻辑
  • 不确定性被显式建模（熵阈值 / 双路径校验 / 去噪后验），而非被动靠 beam size 硬扛；
  • 扩展候选池后必有混合重排兜底（离散置信 + 连续相似 / item 级复打分）；
  • 全部带线上验证，说明解码改造已具备工程成熟度。
🔥 仍需警惕
  • 通配符 / 双路径会放大候选池，下游算力预算需重新分配；
  • 层级路径重排依赖层级语义一致性度量，度量本身的偏差会传导为排序偏差；
  • 扩散路线延迟问题未根治，p99 尾延迟是工业红线。

CoGR：It Takes Two to Match — Co-Evolving Generative Retriever with Reinforcement Learning

arXiv 2609.00638 2026-09-01（约） UNC + Apple 兼容存量倒排基建
动机

近期用 LLM 改造检索的工作大多只优化查询侧（query 扩展 / 数据合成 / 检索反馈训练），最终匹配仍交给下游检索器；而语义鸿沟是双端问题——query 说"保暖衣物"，item 说"冬季夹克"，只改一端治标不治本。

方法
  • 双生成器：query 侧生成器 $G_q$ 与 item 侧生成器 $G_i$ 各自产生一组紧凑关键词，经标准倒排索引直接匹配——完全保留存量关键词检索基建；
  • 两阶段训练：SFT 首先建立对齐的关键词空间 → 协同进化 RL 用 GRPO 交替优化两侧，每侧以对方冻结的索引为参照；
  • 奖励设计：两侧优化同一检索 F1 目标；query 侧直接获得检索 F1，item 侧接收反事实边际奖励（衡量其生成的关键词所引起的 query 侧 F1 变化）。
结果

超 10 个稀疏/稠密/生成式基线内部 APP Marketplace F1 +10.9%WANDS F1 +36.1%

评价

半月内工程参考价值最高的工作之一：①"生成式表示 + 存量倒排"的组合绕开了 SID 标识符设计与解码可扩展性的全部难题；②反事实边际奖励把"双边博弈"转化为可计算的因果增量，对任何双端（query-item / user-item）GR 的奖励工程都有直接借鉴意义；③训练中双侧关键词空间持续对齐的机制值得单独精读。与 SID 生成式检索相比，CoGR 是"不动索引改表示"的另一极，两者在真实系统中可能互补共存。

📄 原文：arxiv.org/abs/2609.00638 · 解读：AGI Hunt

4.2 EG-GRPO：稀疏奖励环境的"专家引导"

天猫 CQ-SID 中的 EG-GRPO（Expert-Guided GRPO）针对的是生成式召回 RL 的一个实际痛点：稀疏奖励——很多 rollout 群组内没有任何正样本，组内相对优势估计退化为噪声。其解法是直接向策略梯度群组注入真实 GT 样本，保证每个群组内有"专家动作"作为锚点，稳定学习过程，最终把生成式召回的产出与下游排序的曝光分布对齐。这与内部号内搜 GR 实践中"GRPO 通过 MCP 获取线上 CTR 分作为 reward，beam=80 / rollout=64 下可有效收敛"的经验互为印证：奖励密度是 GRPO 在召回场景能否收敛的第一决定因素，"注入专家/业务分"与"线上实时分"是两条可行的密度补充路径。

对奖励工程的三个可迁移模式 ① 群组内锚点（EG-GRPO 注入 GT）——解决稀疏奖励下的优势估计退化；② 反事实分解（CoGR 边际奖励）——把多主体博弈归因到单侧动作；③ 业务分直连（内部 CTR 分 reward / EAGER 混合奖励）——让 RL 目标与后验指标同源。三者可组合使用。

arXiv 2609.08860 2026-09-08 IRISA / CNRS 首个完整开源 DSI
动机

DSI（Tay et al., 2022）是生成式检索的事实标准基线，但存在严重可复现性问题：没有任何公开实现完整覆盖原始论文的三种文档标识符类型；已报道的实验结果差异很大；常用数据集 NQ320K 的预处理多样且欠规范。

  • 可参数化、文档完善的 NQ320K 构建流水线；

PDMR：Passage-Driven Multi-ID Document Retrieval — 段落驱动的多 ID 文档检索

arXiv 2609.08762 2026-09-09 IRIT / UPS（Smail Oussaidene, Mohand Boughanem） 长异构文档
动机

生成式检索的结构性弱点：一篇长/异构文档包含多个实体与主题，却被压缩成单一 docid，query 命中文档任一侧面都只能经由同一个 ID，细粒度匹配能力受限。

方法
  • 按段落构造多 ID 表示：一篇文档由多个段落级标识符共同索引；
  • 探索 ID 组成方式与索引顺序：实验表明最优组合为"文档标题 + 段落标题"（TC-ID），并对比 document-first / passage-first 两种排布。
评价

6.2 一个重要的反直觉洞察："无 ID 的 LLM 生成式推荐"

同一 LinkedIn 系团队的另一篇 RecSys 2026 论文（LLMs for Generative Recommendation without IDs）在社交媒体引发讨论：他们发现用 ID（或语义 ID）对 LLM 做 post-training 会"灾难性地破坏" LLM 的原有能力（世界知识、推理、泛化），因此探索让 LLM 原生生成推荐、完全不引入 ID/SID token 的路线。配套论文 Understanding ID-Text Complementarity in Sequential Recommendation 进一步给出结论：ID 特征与文本特征都必要，但简单拼接即可达到 SOTA，复杂的融合策略并不需要。

🧭 对"SID 化 LLM"路线的提醒
  • SID token 挤占 LLM 词表与容量，通用能力损失与 SID 训练强度正相关；
  • 若召回模型同时承担生成/推理任务，需评估"灾难性遗忘"代价（与内部 2 月工作日志中"号内搜场景解决了架构效率，优化目标局限仍有长路"的判断一致）。
✅ 折中路线仍占主流
  • 召回专用小模型做 SID 生成（TIGER/BARGE 路线），LLM 只做内容理解与数据合成；
  • EGR（Snap，2026-07）的"嵌入原生 GR"是另一折中：共享 LLM 但直接索引稠密向量、不生成离散 ID。

7.2 深度拆解：CQ-SID —— 搜索召回场景最完整的落地模板

天猫 9 月 4 日发布的 CQ-SID 是半月内搜索场景信息量最大的落地披露，其完整决策链值得逐条对照：

定位决策：为什么不做端到端？

文章明确列举搜索场景四挑战：①搜索结果对准确性/相关性要求极高，端到端生成在上亿商品池的马太效应与长尾覆盖存疑；②SID"一物一 ID"过细会导致训练样本不足 + beam size 暴涨；③商品池动态演化，参数化索引的增量更新难；④召回目标与下游排序一致性。结论：生成式检索定位为搜索召回中的一路补充。

SID 设计："语义簇"而非"单商品"

不追求低碰撞率，把 SID 视为语义簇标识：类目感知的第一级码本（1711 个有效二级类目强制约束）+ Query-Item 对比学习 + 大簇随机后处理分割，码本 2048×1024×1024。三特性：语义聚合性、区分度保障、层次化前缀结构。

渐进式 SFT：三步建立 query→SID 映射

Step1 Item2SID（Qwen2.5-0.5B 学商品文本→SID 层次结构）→ Step2 Query2SID → Step3 (User+Query)2SID，逐级引入个性化。

EG-GRPO：召回与排序曝光对齐

专家引导的群组相对策略优化：向策略梯度群组注入真实 GT 样本，在稀疏奖励环境中稳定学习，最终让生成式召回产出与下游排序曝光对齐。

可迁移的三条经验 ①"语义簇式 SID"（容忍碰撞、控制簇规模）在搜索召回是可行且更工程友好的选择，与内部"号内搜 beam=40 下每 SID 平均召回 19 个视频"的实况一致；②渐进式课程 SFT（item→query→user+query）是低成本建立个性化映射的通用配方；③召回 RL 的第一目标是"与下游排序曝光对齐"，而非盲目最大化命中率。

7.3 快手 RaG：生成式召回的下一站是"生成供给"

RaG（快手 + 北航，08-31）把生成式召回推到逻辑终点：GRM 预测的 D-SID 不再反查内容池，而是直接作为生成指令驱动视频生成——当用户兴趣落在现有内容池之外时，系统依然可以供给。4 亿 DAU 广告场景 A/B 收入 +1.87%。这与"内容供给型平台"（搜索/推荐/广告一体）的演进方向吻合：召回的边界从"检索已有"扩展到"按需生成"。短期看是广告场景的差异化能力，长期看可能改写"召回-内容池"的关系定义。

趋势研判 业务启发 可落地建议

8.1 五条趋势判断

🎯
① 从"一物一 ID"到"多粒度 ID 体系"

语义簇 SID（CQ-SID）、段落多 ID（PDMR）、query/doc 非对称 ID 数（UniDex 3 vs 8）共同表明：碰撞不是缺陷而是可调的粒度旋钮，ID 体系将按召回场景分层设计。

🧮
② 解码成为显式优化面

通配符（WIDE）、双路径校验（BARGE）、扩散后验（EPIC）、自适应 trie（BONSAI）：解码策略从"超参"升级为"结构"，不确定性的显式建模是下一阶段的公共命题。

⚔️
③ RL 对齐标准化 + 奖励工程竞赛

GRPO 成为事实标准，差异化转移到奖励设计：专家引导锚点（EG-GRPO）、反事实分解（CoGR）、业务分直连（内部实践/EAGER）。奖励密度与归因精度决定收敛质量。

🔌
④ 与存量基建共存压倒"替换叙事"

CoGR 走倒排、CQ-SID 做补充路、LIGER/COBRA 式混合召回：工业落地共识是共生而非替代。生成式召回的 KPI 是"增量覆盖与长尾收益"，而非推翻链路。

📐
⑤ 评测与可复现基建补课

ReDSI（协议统一）+ 碰撞感知评测（05 月）+ FORGE（免训练 SID 评估）构成三层评测栈；论文可信度与离线指标解读将更依赖协议对齐。

🎬
⑥ 召回边界扩展到"生成供给"

RaG 证明 D-SID 可直接驱动内容生成；当兴趣落在池外，"召回"变成"供给"。内容型平台的召回-生产边界开始融合，广告场景先行。

8.2 对搜一搜视频搜索 GR 召回的五条建议

结合内部实践（号内搜 GR 已推全、视频搜索 GR 资源优化与 hitrate@10 / PNR 迭代中，见内部工作日志）与本次半月调研：

① 解码侧引入"不确定性显式化"试点

当前依赖 beam size 硬扛（beam=40，平均每 SID 召回 19 个视频，仍有优化空间）。可借鉴 WIDE 的 AET+通配符思路：对高熵解码步发出通配符并进入混合重排，用结构化扩展替代无差别加大 beam，预期在 hitrate@10 与延迟间取得更优的帕累托前沿。

② SID 簇规模治理：从"碰撞率"转向"簇画像"

参考 CQ-SID 的大簇后处理分割与内部 1 月实验（高重复 SID 还原向量余弦 0.93~0.97）：建立簇级画像（挂载数、簇内相似度分布、hitrate 贡献），把"拆分到空闲 SID"从临时操作变成例行治理动作，直接服务 hitrate@10 提升。

③ RL 奖励工程升级：GRPO + 排序曝光对齐

内部已验证"线上 CTR 分作为 GRPO reward 可收敛"（beam=80/rollout=64）。下一步可组合 EG-GRPO 的群组内 GT 锚点（解决稀疏奖励群组）与 CoGR 的反事实边际奖励思想（归因到单 token 动作），同时优化 hitrate@10 与 PNR。

④ 与关键词/向量通道的"共存活"设计

CoGR 与 CQ-SID 都选择与存量基建共生。视频搜索 GR 的定位也应保持"多路召回中的生成式增强路"：以增量覆盖、长尾/冷启 query 收益、后验增益为北极星指标，避免与成熟通道比拼存量头部 query 的命中。

⑤ 评测协议先行：碰撞审计 + 层级指标双轨

推全扩大影响面后，离线指标的解释成本会放大。建议例行化两件事：SID 碰撞/簇规模审计（对齐 ReDSI 与碰撞感知评测的精神）与层级 hitrate（第 3/4 层分开）监控，让"离线涨幅 → 线上收益"的传导链可解释。

一句话总结 这半月的生成式召回：学术上在"SID 几何、解码不确定性、RL 奖励工程"三个纵深推进，工业上完成了"从推荐到搜索、从替换到共生、从检索到供给"的三级跳。对搜一搜而言，最有性价比的跟进顺序是：簇治理 → 解码试点 → 奖励升级，三者均可复用现有 GR 链路，无需推翻重来。
